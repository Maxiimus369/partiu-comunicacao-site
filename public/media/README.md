# Inserção de mídias

1. Salve o arquivo na subpasta correspondente.
2. Converta fotografias para WebP ou AVIF e mantenha dimensões conhecidas.
3. Para vídeos, prefira MP4 H.264; crie versão mobile e poster quando necessário.
4. Atualize somente o item correspondente em `src/data/media-slots.ts`.
5. Preencha `src`, `poster`, `alt`, `credit`, `instagramUrl` e dimensões.
6. Altere `authorizationStatus` para `authorized` apenas depois da confirmação de uso.

Não use hotlink do Instagram ou Canva e não dependa de URLs temporárias.
